# Code of Conduct

## Our Commitment

Synteles is an open-source project for AI workers and enterprise workflow automation.

We are committed to providing a respectful, inclusive, and harassment-free environment for everyone participating in the project, regardless of experience level, background, identity, nationality, language, location, or role.

We want Synteles to be a community where users, contributors, maintainers, and organizations can collaborate constructively.

## Expected Behavior

Participants are expected to:

- Be respectful and professional
- Communicate clearly and constructively
- Assume good intent where reasonable
- Give and receive feedback with care
- Focus discussions on technical merit, project goals, and user value
- Respect different experience levels and perspectives
- Help maintain a productive environment for users, contributors, and maintainers

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment, intimidation, threats, or personal attacks
- Discriminatory language or behavior
- Sexualized language, imagery, or attention
- Trolling, insults, or deliberate disruption
- Repeatedly derailing technical discussions
- Publishing private information without consent
- Impersonation or misrepresentation
- Abusive, aggressive, or hostile communication
- Any behavior that would reasonably be considered inappropriate in a professional open-source community

## Project Spaces

This Code of Conduct applies to all Synteles project spaces, including:

- GitHub repositories
- Issues and pull requests
- Discussions and comments
- Documentation and examples
- Community channels
- Events, calls, or meetings related to the project
- Any other communication connected to the Synteles project

It also applies when an individual is representing the project in public spaces.

## Reporting

If you experience or observe unacceptable behavior, please contact the project maintainer:

```text
hello@synteles.io
```

Please include as much context as you are comfortable sharing, such as:

- What happened
- Where it happened
- When it happened
- Who was involved
- Links, screenshots, or other relevant information, if available

Reports will be handled with discretion.

## Enforcement

Project maintainers may take appropriate action in response to unacceptable behavior, including:

- Asking the participant to stop the behavior
- Warning the participant
- Removing comments, issues, pull requests, or discussions
- Temporarily or permanently limiting participation in the project
- Blocking or banning a participant from project spaces
- Reporting behavior to GitHub or other relevant platforms where appropriate

Enforcement decisions are made by the project maintainer.

## Maintainer Responsibilities

Maintainers are responsible for clarifying standards of acceptable behavior and are expected to take appropriate and fair action in response to violations of this Code of Conduct.

Maintainers may remove, edit, or reject contributions, comments, commits, issues, pull requests, or other content that is not aligned with this Code of Conduct.

## Scope of Enforcement

This Code of Conduct is intended to protect project participants and maintain productive collaboration.

It is not intended to restrict respectful disagreement, technical debate, or good-faith criticism. Disagreement is acceptable; harassment and abuse are not.

## Attribution

This Code of Conduct is inspired by common open-source community standards and adapted for the Synteles project.

## Updates

This Code of Conduct may be updated as the project and community evolve.
