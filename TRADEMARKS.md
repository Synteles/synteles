# Trademark and Brand Guidelines

The Synteles source code is licensed under the Apache License, Version 2.0, unless otherwise stated.

The Synteles name, logo, visual identity, and related brand assets are not licensed under the Apache License, Version 2.0.

This document explains how the Synteles name and brand assets may be used.

## Reserved Brand Assets

The following brand assets are reserved by the project maintainer:

- The name `Synteles`
- The Synteles logo
- Synteles visual identity assets
- Synteles website, documentation, and project branding
- Related names, marks, graphics, and design elements that identify the Synteles project

These assets may not be used in a way that suggests endorsement, sponsorship, affiliation, or an official relationship with the Synteles project without prior written permission.

## Permitted Use

You may use the Synteles name for fair and accurate reference, such as:

- Referring to the Synteles open-source project
- Linking to the official Synteles repository
- Describing compatibility with Synteles
- Writing tutorials, blog posts, articles, reviews, or documentation about Synteles
- Identifying forks or derivative works as being based on Synteles
- Discussing Synteles in presentations, research, or educational material

Examples of acceptable use:

```text
This connector is compatible with Synteles.
This project is based on the Synteles open-source platform.
This tutorial explains how to build an AI worker with Synteles.
```

## Not Permitted Without Permission

You may not use the Synteles name, logo, or brand assets without prior written permission to:

- Name your own product, company, service, distribution, or commercial offering
- Suggest that your project, service, or distribution is official or endorsed by Synteles
- Use the Synteles logo in marketing, sales, or product materials
- Register domains, package names, social media handles, trademarks, or accounts that imply official Synteles ownership
- Use confusingly similar names or branding for competing or derivative products
- Remove, obscure, or alter attribution in a misleading way
- Present a modified version of Synteles as the official Synteles project

## Forks and Modified Versions

You may fork and modify the Synteles source code under the terms of the Apache License, Version 2.0.

If you distribute a modified version, you must make clear that your version is independent and not the official Synteles project unless you have written permission.

Suggested wording:

```text
This is an independent fork of Synteles and is not affiliated with or endorsed by the Synteles project maintainer.
```

You should not use the Synteles logo or visual identity for modified distributions unless you have written permission.

## Compatibility Statements

You may truthfully describe compatibility with Synteles.

Acceptable examples:

```text
Compatible with Synteles
Connector for Synteles
Integration with Synteles
Workflow template for Synteles
```

Avoid names that imply official status unless authorized.

Not acceptable without permission:

```text
Official Synteles Connector
Synteles Enterprise Edition
Synteles Cloud
Certified by Synteles
```

## Packages, Domains, and Accounts

Do not register or publish package names, domains, social media handles, marketplace listings, or accounts that could be confused with official Synteles assets.

Examples requiring permission:

```text
synteles-cloud.example
synteles-enterprise.example
@synteles-official
synteles-certified-connector
```

If you are unsure whether a name could cause confusion, contact the project maintainer before using it.

## Attribution

When referring to Synteles, please link to the official repository or website where practical.

Recommended attribution:

```text
Synteles is an open-source project maintained by Emin Askerov.
```

## No Implied Endorsement

Use of the Synteles name for fair reference does not imply endorsement, certification, partnership, sponsorship, or approval by the Synteles project maintainer.

